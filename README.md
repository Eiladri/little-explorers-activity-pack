# Little Explorers — Animal Activity Pack

A responsive landing page for Little Explorers: Animal Activity Pack, a printable animal-themed activity PDF for children ages 3–5.

The page introduces the product, highlights its activities, and directs customers to Payhip checkout.

## Product Details

- **Format:** Digital PDF
- **Age Range:** 3–5 years
- **Activities:** 10 animal-themed activities
- **Price:** ₹21
- **Delivery:** Digital delivery through Payhip after successful purchase

## Features

- Responsive desktop and mobile layout
- Green, cream, and orange theme
- Embedded animal-themed cover artwork
- Sticky navigation with active-section highlighting
- Mobile navigation menu
- Product description and activity highlights
- Contact section with clickable email
- Privacy policy, terms, refund policy, and digital-delivery information
- Purchase buttons connected to Payhip checkout

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

No frontend framework or build step required.

## Run Locally

1. Clone or download this repository.
2. Open `index.html` in your browser.

## Deployment

This website can be hosted for free with GitHub Pages.

1. Upload `index.html` to the repository root.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose `main` and `/(root)`.
5. Click **Save**.

## Important Notes

- This repository contains the public landing page, not the paid PDF.
- Never commit API keys, payment secrets, passwords, or private customer information.
- Payhip handles checkout and digital-product delivery according to the product's configured settings.
- Keep the displayed price and checkout link synchronized with the Payhip listing.
